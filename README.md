# Milkman (milkman)
Milkman is an open-source, JavaFx-based, plugin-driven request/response workbench and desktop alternative to Postman and Insomnia. It supports multiple protocols including HTTP/REST, GraphQL, gRPC (with server reflection and streaming), WebSocket, Socket.IO, JDBC/SQL, Cassandra CQL, and Model Context Protocol (MCP).

## APIs

### Milkman
Milkman is an extensible request/response workbench for various protocols like HTTP, gRPC, GraphQL, WebSocket, Socket.IO, JDBC/SQL, Cassandra, and MCP. The plugin-based desktop application supports workspaces, environments, collections, OAuth, Postman/Insomnia import, Git-based team sync, a CLI for terminal usage, and a test runner for sequential request execution.
